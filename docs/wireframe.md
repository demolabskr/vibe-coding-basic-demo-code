# 와이어프레임

화면 흐름과 화면마다 들어갈 요소를 글로 옮긴 와이어프레임이다. 네모는 화면, 화살표는 버튼을 눌렀을 때 이동하는 방향이다.

```text
1 목록 → 2 상세 → 3 로그인(처음이면 가입) → 4 결제 → 5 결제 완료 → 6 내 자료실(내려받기)
```

## 1. 목록 `/contents/`

```text
┌──────────────────────────────────────────────┐
│ 민지의 자료 가게        콘텐츠  내 자료실  로그인 │
├──────────────────────────────────────────────┤
│ [전체] [전자책] [강의 영상] [서식]              │
│ ┌────────┐ ┌────────┐ ┌────────┐            │
│ │ 표지    │ │ 표지    │ │ 표지    │            │
│ │ 종류    │ │ 종류    │ │ 종류    │            │
│ │ 제목    │ │ 제목    │ │ 제목    │            │
│ │ 가격    │ │ 가격    │ │ 가격    │            │
│ └────────┘ └────────┘ └────────┘            │
└──────────────────────────────────────────────┘
```

- 카드를 누르면 상세로 간다. 휴대폰에서는 한 줄에 카드 한 장.

## 2. 상세 `/contents/<slug>/`

```text
┌──────────────┬───────────────────────────────┐
│              │ 종류                           │
│   표지        │ 제목                           │
│              │ 한 줄 소개                      │
│              │ 가격(할인가가 있으면 원래 가격에 줄) │
│              │ [구매하기]                      │
├──────────────┴───────────────────────────────┤
│ 설명                                          │
└──────────────────────────────────────────────┘
```

- 이미 산 사람에게는 [구매하기] 대신 [내 자료실에서 받기].

## 3. 로그인 `/accounts/login/`, 가입 `/accounts/signup/`

- 아이디, 비밀번호, [로그인]. 아래에 "처음이면 가입", "비밀번호를 잊었다면".
- 가입: 아이디, 메일, 비밀번호, 비밀번호 확인, 개인정보 처리 안내 링크.

## 4. 결제(주문 확인) `/orders/<주문 번호>/`

- 주문 번호, 콘텐츠 제목, 금액, [결제하기].
- 카드 정보를 받는 결제창은 결제 대행 서비스가 띄운다(이 저장소에서는 가상 결제창).

## 5. 결제 완료 `/payments/success/`

- "결제가 끝났습니다", 주문 번호, [내 자료실로 가기].

## 6. 내 자료실 `/library/`

- 로그인한 사람이 산 콘텐츠만 보인다.
- 줄마다 표지, 제목, 결제 시각, [내려받기] 또는 [보기](영상).

## 운영자 관리 화면 `/admin/`

- 콘텐츠: 목록(제목, 종류, 가격, 공개 여부, 등록 시각), 검색, 등록과 수정.
- 주문: 목록(주문 번호, 구매자, 콘텐츠, 금액, 상태, 결제 시각), 상태로 거르기, 판매 기록 CSV 내려받기.
