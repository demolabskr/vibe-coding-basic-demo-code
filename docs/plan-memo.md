# 기획 메모

만들기 전에 한 문단으로 적은 메모다. 새 대화를 시작할 때마다 AI에게 이 메모를 첫머리에 붙여 넣는다.

> 내가 쓴 전자책과 강의 영상, 서식 파일을 개인 독자에게 파는 작은 사이트다. 구매자는 가입하고 로그인한 뒤 결제하고, 산 파일을 내려받는다. 혼자 만든 자료를 직접 팔고 싶어서 만든다. 이번에는 가입과 로그인, 상품 목록, 상세, 결제, 내려받기, 운영자 관리 화면까지 만들고, 쿠폰과 후기 기능은 만들지 않는다.

## 네 가지 점검

| 항목 | 메모의 문장 |
|---|---|
| 누구에게 | 개인 독자에게 |
| 무엇을 | 전자책, 강의 영상, 서식 파일을 팔고, 산 사람이 내려받는다 |
| 왜 | 혼자 만든 자료를 직접 팔고 싶어서 |
| 어디까지 | 가입과 로그인, 목록, 상세, 결제, 내려받기, 관리 화면. 쿠폰과 후기는 만들지 않는다 |

자세한 요구 사항은 [PRD.md](PRD.md)에 적었다.
