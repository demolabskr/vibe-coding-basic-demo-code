# PRD: 민지의 자료 가게

PRD(Product Requirements Document)는 무엇을 왜 만드는지, 어디까지 만드는지를 적은 제품 요구 사항 문서다. [기획 메모](plan-memo.md) 한 문단을 AI와 함께 풀어 쓴 것이고, 요청할 때마다 AI가 이 문서를 기준으로 삼는다.

- 문서 상태: 첫 판(MVP) 기준
- 이 사이트는 책 「바이브 코딩 기초 지식」을 위해 만든 예시다. 지은이 민지와 가게는 가상이다.

## 1. 목적

혼자 만든 전자책, 강의 영상, 서식 파일을 개인 독자에게 직접 판다. 지금은 메신저로 주문을 받아 파일을 하나씩 보내고 있어 시간이 들고, 누가 무엇을 샀는지 기록이 흩어져 있다. 사이트가 결제와 전달을 맡고, 운영자는 콘텐츠 등록과 주문 확인만 한다.

## 2. 사용자와 역할

| 역할 | 누구인가 | 할 수 있는 일 |
|---|---|---|
| 방문자 | 로그인하지 않은 사람 | 목록과 상세 보기, 가입 |
| 구매자 | 가입하고 로그인한 사람 | 결제, 내 자료실에서 산 콘텐츠 내려받기와 열람 |
| 운영자 | 사이트 주인(민지) | 관리 화면에서 콘텐츠 등록·수정·숨김, 주문 확인, 판매 기록 내려받기 |

## 3. 첫 판 기능(MVP)

| 번호 | 기능 | 끝나는 기준 |
|---|---|---|
| F1 | 가입과 로그인 | 가입, 로그인, 로그아웃, 비밀번호 재설정이 된다 |
| F2 | 콘텐츠 목록 | 공개된 콘텐츠만 카드로 보인다. 휴대폰에서는 한 줄에 한 장 |
| F3 | 콘텐츠 상세 | 표지, 종류, 제목, 설명, 가격, 구매 버튼이 보인다 |
| F4 | 결제 | 결제 대행 서비스의 결제창에서 결제하고, 서버가 결제 결과를 다시 확인한다 |
| F5 | 내려받기와 열람 | 결제를 마친 구매자만 받는다. 영상은 사이트 안에서 본다 |
| F6 | 운영자 관리 화면 | 콘텐츠를 올리고 숨기고, 주문을 확인한다 |

### 다음 판으로 미룬 것

- 구매 알림 메일(첫 판 마무리 단계에서 넣었다)
- 후기, 쿠폰, 찜하기, 추천
- 소셜 로그인
- 환불 처리 화면(운영자가 결제 대행 서비스 관리 화면에서 처리한다)
- AI 요약 같은 AI 기능

## 4. 화면 흐름

```text
1 목록 → 2 상세 → 3 로그인(처음이면 가입) → 4 결제 → 5 결제 완료 → 6 내 자료실(내려받기)
```

화면마다 들어갈 요소는 [wireframe.md](wireframe.md)에 적었다.

## 5. 데이터

| 표 | 담는 것 | 이어지는 표 |
|---|---|---|
| 회원(User) | 아이디, 메일, 비밀번호 해시 | 주문 여러 건 |
| 콘텐츠(Content) | 종류, 제목, 주소용 이름(slug), 설명, 가격, 할인가, 표지, 판매 파일, 공개 여부 | 주문 여러 건 |
| 주문(Order) | 주문 번호, 구매자, 콘텐츠, 금액, 상태, 결제 키, 결제 시각 | 회원 하나, 콘텐츠 하나 |

- 판매 파일은 공개 주소가 없는 곳(`private/`)에 둔다. 표지는 누구나 볼 수 있는 `media/`에 둔다.
- 금액은 원 단위 정수로 저장한다.
- 시각은 UTC로 저장하고 화면에는 한국 시간으로 보인다.

## 6. 결제 규칙

- 카드 정보는 이 사이트가 받지 않는다. 결제창은 결제 대행 서비스가 띄운다.
- 결제창에서 돌아올 때 주소에 붙어 오는 금액과 상태는 믿지 않는다. 서버가 결제 대행 서비스에 결제 키로 다시 묻고, 받은 금액이 주문 금액과 같을 때만 결제 완료로 바꾼다.
- 결제 대행 서비스가 보내는 웹훅도 받는다. 서명이 맞는 알림만 처리하고, 같은 알림이 두 번 와도 주문은 한 번만 완료된다.
- 저장소에는 실제 결제 대행 서비스를 연결하지 않는다. 같은 흐름을 흉내 내는 `fakepg`(가상 결제 서비스)를 쓰며 실제 돈은 오가지 않는다.

## 7. 비기능 요구

- 스택: Python, Django. 데이터베이스는 개발 중 SQLite, 운영은 PostgreSQL.
- 비밀 값(비밀 키, 결제 키, 메일 비밀번호)은 `.env`와 환경 변수에만 둔다. 저장소에는 `.env.example`만 올린다.
- 운영에서는 디버그 모드를 끄고 HTTPS로만 로그인 쿠키를 보낸다.
- 화면은 휴대폰 폭에서도 가로로 밀리지 않는다.
- 구매하지 않은 사람이 내려받지 못한다는 것을 자동 테스트로 확인한다.

## 8. 만들지 않는 것

판매 전략, 세금 계산, 정산, 여러 판매자. 이 사이트는 판매자 한 사람의 작은 가게다.
